ABS(): Returns the absolute value of a numeric expression. 
SELECT ABS(-10) AS absolute_value; -- Result: 10 ROUND off
ROUND(): Rounds a numeric value to a specified number of decimal places. 
SELECT ROUND(3.14159, 2) AS rounded_value; -- Result: 3.14 CEILING 
CEIL() or CEILING(): Returns the smallest integer value greater than or equal to a numeric expression. 
SELECT CEIL(5.2) AS ceil_value; -- Result: 6
FLOOR 
FLOOR(): Returns the largest integer value less than or equal to a numeric expression. 
SELECT FLOOR(5.8) AS floor_value; -- Result: 5 POWER 
POWER(): Raises a numeric value to a specified power. 
SELECT POWER(2, 3) AS power_value; -- Result: 8 (2^3) MODULUS 
MOD(): Returns the remainder of a division between two numbers. 
SELECT MOD(10, 3) AS modulus_value; -- Result: 1 (10 % 3) SQUARE ROOT ^2 
SQRT(): Returns the square root of a non-negative numeric value. 
SELECT SQRT(25) AS square_root_value; -- Result: 5 (sqrt(25) = 5) RANDOM 
RAND(): Returns a random floating-point value between 0 and 1. 
SELECT RAND() AS random_value; -- Result: Random value between 0 and 1
